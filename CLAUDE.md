## Commands

- `npm run dev` — start the dev server (http://localhost:3000)
- `npm run build` — production build (also runs type checking)
- `npm run start` — serve the production build
- `npm run lint` — ESLint (flat config in `eslint.config.mjs`, extends `eslint-config-next` core-web-vitals + typescript)
- `npx tsc --noEmit` — type check only

No test framework is configured yet.

## Stack

- Next.js 16 (App Router) with React 19 and TypeScript (strict). Per `AGENTS.md`, this Next.js version differs from older releases — check `node_modules/next/dist/docs/` before using framework APIs.
- Tailwind CSS v4, wired through PostCSS (`@tailwindcss/postcss`). There is no `tailwind.config.js`; Tailwind is loaded via `@import "tailwindcss";` in `src/app/globals.css`, and theme customization goes in a CSS `@theme` block there.
- Path alias `@/*` → `src/*`.

## Structure

- All routes live under `src/app/` (App Router). `layout.tsx` is the root layout: it imports `globals.css` and loads the Geist / Geist Mono fonts via `next/font/google` as the CSS variables `--font-geist-sans` / `--font-geist-mono`.
- Layout props use the globally available `LayoutProps<"/">` type helper (generated by Next.js) rather than hand-written prop types.
- `src/app/page.tsx` is currently a stripped placeholder (`<h1>Devstash</h1>`); the starter boilerplate, default styles, and `public/` SVGs have been removed.
